# Tasks over IMAP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tasks that live in the user's own IMAP account (an email with a VTODO part in a `Tasks/` folder), synced by the daemon and usable from the CLI, MCP and the GUI, with desktop reminders.

**Architecture:** A new top-level `tasks` module holds the model, the VTODO codec, quick add, the task message format, indexing and the write sequence; it depends on `store`, the `MailOps` trait, `message` and `chrono`, never on `engine`, `paths`, `credentials` or `notify`. The account sync thread indexes task folders after every pass and every command, and runs task writes as one new `Command::Task`, so every front end goes through the daemon as mail actions do. Reads (lists, views, reminders) are SQL on a new `tasks` table that cascades away with its message row.

**Tech Stack:** Rust 2024, rusqlite 0.40 + rusqlite_migration, mail-parser 0.11, **mail-builder 1.0 (new)**, chrono 0.4 (`std`, `clock`), clap 4, rmcp 3.5, eframe/egui 0.36, egui_kittest.

**Spec:** `docs/superpowers/specs/2026-10-09-tasks-design.md`

**Prerequisite:** the rename to Postvak (postvak-app/postvak#111) is merged. This plan uses the new names: the `postvak` crate, `POSTVAK_*` variables and `X-POSTVAK-LIST`.

## Decisions (the owner can veto any of these before Task 1)

These settle the spec's three "verify during planning" points and the places where the code differs from what the spec assumed.

1. **Retention rule: verified, works as written.** `older_than` compares against `msg.internaldate` (`src/rules/engine.rs:139-140`), which is the server's INTERNALDATE (`src/mail_ops/imap.rs:196`). `MailOps::append` passes no date (`imap.rs:369`), so a completed task's INTERNALDATE is its completion time. `older_than` is parsed by `humantime::parse_duration`, which accepts `90days` (`humantime-2.4.0/src/duration.rs:329`: `"days" | "day" | "d"`). Rules evaluate all stored mail on each pass, and a rule only acts on mail newer than its `first_seen_at`. A retention rule added today therefore never touches tasks completed before today, which is fine. `docs/src/tasks.md` says so.
2. **No desktop-only dependencies, but not under `engine`.** `postvak::engine` is `src/engine.rs`, the per-account thread orchestrator. It holds `Paths` and drives `sync`, which reaches `credentials` (keyring) and `ImapOps`. Task logic therefore goes in a new top-level `src/tasks/`, not `engine::tasks`. `tasks/` uses only `store`, the `MailOps` trait, `message`, `trash`, `config::AccountConfig`, `chrono` and `mail-builder`, so an Android build can reuse it with its own `MailOps`. `store` takes `Paths` only in `Store::open_account`, which `tasks` never calls. `tests/architecture.rs` gains a rule that keeps it that way (Task 7).
3. **Migration 008, not 004.** Migrations 001–007 exist (`migrations/`).
4. **No APPENDUID.** `MailOps::append` returns nothing, and neither the spec's step 1 nor anything else needs the new UID. Task identity is the VTODO `UID`, and the folder sync after the write (`sync_now`, as `Apply` and `Restore` already do) indexes the new version. The write sequence is: APPEND the new version, then `\Deleted` and expunge the old one, then sync the folder. That keeps "write first, delete after". On servers without UIDPLUS, `ImapOps::expunge` refuses while another message in the folder carries `\Deleted` (#105). An edit then fails after its append and leaves two copies. The index settles them once the other client's flagged mail is gone, and until then views show only the winner.
5. **The tasks root is per account: `tasks_folder` in `[[accounts]]`, default `"Tasks"`.** The spec's top-level `[tasks] folder` does not reach the sync threads, which only get an `AccountConfig`. Servers with an `INBOX.` namespace need `INBOX.Tasks` anyway. List folders are joined with the server's delimiter from `folders.delimiter`, not a hard-coded `/`.
6. **New dependency `mail-builder = { version = "1", default-features = false }`.** It is the composing sibling of `mail-parser`, from the same author. It handles RFC 2047 subjects, multipart boundaries, and `message/rfc822` attachments sent as `8bit` with no base64 (checked in `mail-builder-1.0.0/src/mime.rs:400-435`). `default-features = false` drops `gethostname`, because Postvak writes its own `Message-ID`.
7. **The VTODO codec is hand-written (about 250 lines), not the `icalendar` crate.** The spec requires that properties Postvak does not understand survive every rewrite byte for byte. The codec keeps every content line it does not own as raw text, in order, so this holds by construction.
8. **`TZID` times are read as local time.** `chrono` here has no timezone database. Postvak writes UTC (`…Z`) and `DATE` values only, so the ceiling only affects tasks written by other apps in a zone other than the user's own. The code marks it with a `ponytail:` comment.
9. **Two new MCP scopes: `tasks:read` (`task_list`, `task_lists`) and `tasks:write` (the four writes).** Neither is in the default `read,rules:propose`. Task text is the user's own data, so it is not wrapped as untrusted mail. Titles taken from mail still go through `message::clean`, as all MCP strings do.
10. **Superseded versions are not backed up to the local trash.** The new version is on the server before the old one is expunged. `task rm` uses the existing delete path, so it does keep a 30-day `.eml`.
11. **Reminders fire once per (task UID, reminder time)**, recorded in a `task_reminders` table. A reminder missed while the machine slept fires on wake if it is less than a day late, and is dropped otherwise.

### Accepted risks

- A second Postvak device editing the same task while offline loses one edit (the spec's "no field-level merge").
- Folder sync after each task write costs one SELECT plus a header fetch. This adds noticeable latency per edit on a slow server. The GUI hides that with optimistic updates (Task 13); the CLI waits.

## Review Focus

1. **A VTODO from another app with properties Postvak doesn't know** (`RRULE`, `RELATED-TO`, `X-APPLE-SORT-ORDER`, a folded 200-character `DESCRIPTION`, a `VALARM` with an `ACTION:AUDIO`, a `TZID` due): an edit keeps every unknown line verbatim and in order. Test in Task 1 (`unknown_properties_survive_a_rewrite`).
2. **Two copies of one task**, from a failed expunge or two devices: the highest `SEQUENCE` wins, then the latest `LAST-MODIFIED`. The loser is expunged on the next sync, and views never show both. Test in Task 6 (`duplicates_keep_the_highest_sequence`).
3. **A date-only due around midnight and across DST** (due `2026-10-25`, the day the clocks change in the EU): it shows in Today on the 25th and in Overdue from 00:00 on the 26th local time, never earlier. Test in Task 4 (`date_only_due_is_overdue_from_the_next_local_day`, run with `TZ=Europe/Amsterdam` set inside the test via a fixed `today`/`now` pair).
4. **Hostile or broken input**: a calendar part that is binary garbage, unterminated `BEGIN:VTODO`, 10 MB of folded lines, or a quick-add string of emoji and `^^^###!!!`. None of these panic. A broken VTODO shows as a read-only task, and editing it is refused. Tests in Task 1 and Task 2 (fuzz cases in `tests/fuzz.rs`) and Task 6 (`unparseable_vtodo_is_read_only`).
5. **An ambiguous or unknown CLI id**: `postvak task done a1` where two UIDs start with `a1`, or none does, is refused, names the candidates, and changes nothing. Test in Task 8 (`ambiguous_id_is_refused`).

```rust
//! Tasks stored as mail: each task is a message with a VTODO part under the account's tasks folder.
//!
//! No platform code lives here (paths, keyring, notifications, the daemon), so the module can be reused by a build
//! that brings its own `MailOps`.

pub mod ical;

use std::hash::{BuildHasher, Hasher};
use std::sync::atomic::{AtomicU64, Ordering};

use chrono::NaiveDate;
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Task {
    pub uid: String,
    /// The list the task belongs to, `""` for Inbox; for a done task, the list it was completed from.
    pub list: String,
    pub title: String,
    pub notes: String,
    pub due: Option<Due>,
    pub priority: Priority,
    pub tags: Vec<String>,
    pub done: bool,
    pub completed_at: Option<i64>,
    pub reminder: Option<i64>,
    pub folder: String,
    pub message_uid: u32,
    /// The VTODO could not be parsed; the task can be deleted but not edited.
    pub read_only: bool,
    /// The task carries a mail as a `message/rfc822` attachment.
    pub has_mail: bool,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum Due {
    Date(NaiveDate),
    At(i64),
}

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize)]
pub enum Priority {
    #[default]
    None,
    Low,
    Medium,
    High,
}

impl Priority {
    pub fn from_ical(value: u8) -> Priority {
        match value {
            1..=4 => Priority::High,
            5 => Priority::Medium,
            6..=9 => Priority::Low,
            _ => Priority::None,
        }
    }

    pub fn to_ical(self) -> u8 {
        match self {
            Priority::None => 0,
            Priority::High => 1,
            Priority::Medium => 5,
            Priority::Low => 9,
        }
    }

    /// The `s` key's cycle: none, high, medium, low, none.
    pub fn next(self) -> Priority {
        match self {
            Priority::None => Priority::High,
            Priority::High => Priority::Medium,
            Priority::Medium => Priority::Low,
            Priority::Low => Priority::None,
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub enum View {
    Inbox,
    List(String),
    Today,
    Overdue,
    Next7,
    Tag(String),
    Done,
}

/// A new VTODO UID: 64 random bits from the std hasher's per-process keys, the clock and a counter.
pub fn new_uid() -> String {
    static COUNTER: AtomicU64 = AtomicU64::new(0);
    let mut hasher = std::collections::hash_map::RandomState::new().build_hasher();
    let nanos = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map_or(0, |d| d.as_nanos());
    hasher.write_u128(nanos);
    hasher.write_u64(COUNTER.fetch_add(1, Ordering::Relaxed));
    format!("{:016x}@postvak", hasher.finish())
}

mod tests {

    #[test]
    fn priority_maps_the_rfc_ranges() {
        assert_eq!(Priority::from_ical(0), Priority::None);
        assert_eq!(Priority::from_ical(3), Priority::High);
        assert_eq!(Priority::from_ical(5), Priority::Medium);
        assert_eq!(Priority::from_ical(7), Priority::Low);
        assert_eq!(Priority::from_ical(42), Priority::None);
        for p in [Priority::None, Priority::Low, Priority::Medium, Priority::High] {
            assert_eq!(Priority::from_ical(p.to_ical()), p);
        }
```

```rust
//! The VTODO subset Postvak reads and writes (RFC 5545). Every content line it does not own is kept as it was, in
//! order, so other apps' properties survive a rewrite.

use chrono::{Local, NaiveDate, NaiveDateTime, TimeZone, Utc};

use super::{Due, Priority};

/// One unfolded content line. `params` is the raw text between the name and the `:`, starting with `;` when present.
#[derive(Debug, Clone, PartialEq)]
pub struct Line {
    pub name: String,
    pub params: String,
    pub value: String,
}

impl Line {
    fn new(name: &str, params: &str, value: impl Into<String>) -> Line {
        Line {
            name: name.to_string(),
            params: params.to_string(),
            value: value.into(),
        }
    }
}

/// A calendar split around its first VTODO: the lines before `BEGIN:VTODO`, the ones inside it (nested components
/// included) and the ones after `END:VTODO`.
#[derive(Debug, Clone, PartialEq)]
pub struct Calendar {
    pub before: Vec<Line>,
    pub todo: Vec<Line>,
    pub after: Vec<Line>,
}

#[derive(Debug, Clone, Default, PartialEq)]
pub struct Fields {
    pub uid: String,
    pub title: String,
    pub notes: String,
    pub due: Option<Due>,
    pub priority: Priority,
    pub tags: Vec<String>,
    pub done: bool,
    pub completed_at: Option<i64>,
    pub reminder: Option<i64>,
    pub original_list: Option<String>,
    pub sequence: u32,
    pub modified: i64,
}

#[derive(Debug, Clone, PartialEq, thiserror::Error)]
pub enum IcalError {
    #[error("the calendar has no VTODO")]
    NoTodo,
    #[error("the VTODO is not closed")]
    Unclosed,
    #[error("calendar line {0} has no ':'")]
    BadLine(usize),
    #[error("the VTODO has no UID")]
    NoUid,
}

pub fn parse(text: &str) -> Result<Calendar, IcalError> {
    let mut cal = Calendar {
        before: Vec::new(),
        todo: Vec::new(),
        after: Vec::new(),
    };
    #[derive(PartialEq)]
    enum At {
        Before,
        Todo,
        After,
    }
    let mut at = At::Before;
    let mut depth = 0usize;
    for (index, raw) in unfold(text).iter().enumerate() {
        if raw.trim().is_empty() {
            continue;
        }
        let line = split(raw).ok_or(IcalError::BadLine(index + 1))?;
        let is = |name: &str, value: &str| line.name == name && line.value.eq_ignore_ascii_case(value);
        match at {
            At::Before if is("BEGIN", "VTODO") => at = At::Todo,
            At::Before => cal.before.push(line),
            At::Todo if depth == 0 && is("END", "VTODO") => at = At::After,
            At::Todo => {
                if line.name == "BEGIN" {
                    depth += 1;
                } else if line.name == "END" {
                    depth = depth.saturating_sub(1);
                }
                cal.todo.push(line);
            }
            At::After => cal.after.push(line),
        }
    }
    match at {
        At::Before => Err(IcalError::NoTodo),
        At::Todo => Err(IcalError::Unclosed),
        At::After => Ok(cal),
    }
}

fn unfold(text: &str) -> Vec<String> {
    let mut lines: Vec<String> = Vec::new();
    for line in text.split('\n') {
        let line = line.strip_suffix('\r').unwrap_or(line);
        match (line.strip_prefix([' ', '\t']), lines.last_mut()) {
            (Some(rest), Some(last)) => last.push_str(rest),
            _ => lines.push(line.to_string()),
        }
    }
    lines
}

/// Splits at the first `:` outside double quotes.
fn split(raw: &str) -> Option<Line> {
    let mut quoted = false;
    for (i, c) in raw.char_indices() {
        match c {
            '"' => quoted = !quoted,
            ':' if !quoted => {
                let head = &raw[..i];
                let (name, params) = head.find(';').map_or((head, ""), |p| (&head[..p], &head[p..]));
                if name.is_empty() {
                    return None;
                }
                return Some(Line::new(&name.to_ascii_uppercase(), params, &raw[i + 1..]));
            }
            _ => {}
        }
    }
    None
}

fn escape(text: &str) -> String {
    let mut out = String::with_capacity(text.len());
    for c in text.chars() {
        match c {
            '\\' => out.push_str("\\\\"),
            ';' => out.push_str("\;"),
            ',' => out.push_str("\\,"),
            '\n' => out.push_str("\\n"),
            '\r' => {}
            c => out.push(c),
        }
    }
    out
}

fn unescape(text: &str) -> String {
    let mut out = String::with_capacity(text.len());
    let mut chars = text.chars();
    while let Some(c) = chars.next() {
        match (c, c == '\\') {
            (_, true) => match chars.next() {
                Some('n' | 'N') => out.push('\n'),
                Some(next) => out.push(next),
                None => out.push('\\'),
            },
            (c, false) => out.push(c),
        }
    }
    out
}

/// Splits a list value at commas that are not escaped.
fn split_list(value: &str) -> Vec<String> {
    let mut items = vec![String::new()];
    let mut escaped = false;
    for c in value.chars() {
        match c {
            ',' if !escaped => items.push(String::new()),
            c => {
                escaped = c == '\\' && !escaped;
                if let Some(last) = items.last_mut() {
                    last.push(c);
                }
            }
        }
    }
    items
        .iter()
        .map(|item| unescape(item).trim().to_string())
        .filter(|item| !item.is_empty())
        .collect()
}

fn format_utc(ts: i64) -> String {
    Utc.timestamp_opt(ts, 0)
        .single()
        .map_or_else(String::new, |t| t.format("%Y%m%dT%H%M%SZ").to_string())
}

/// A DATE-TIME value: UTC with `Z`, otherwise local time.
// ponytail: TZID values are read as local time (no tz database in this build); add chrono-tz if zoned tasks from other apps matter.
fn parse_time(value: &str) -> Option<i64> {
    let value = value.trim();
    if let Some(utc) = value.strip_suffix(['Z', 'z']) {
        return NaiveDateTime::parse_from_str(utc, "%Y%m%dT%H%M%S")
            .ok()
            .map(|t| t.and_utc().timestamp());
    }
    let local = NaiveDateTime::parse_from_str(value, "%Y%m%dT%H%M%S").ok()?;
    Local.from_local_datetime(&local).earliest().map(|t| t.timestamp())
}

fn parse_due(value: &str) -> Option<Due> {
    let value = value.trim();
    if value.len() == 8 {
        NaiveDate::parse_from_str(value, "%Y%m%d").ok().map(Due::Date)
    } else {
        parse_time(value).map(Due::At)
    }
}

/// `[+-]P[nW][nD][T[nH][nM][nS]]` in seconds.
fn parse_duration(value: &str) -> Option<i64> {
    let value = value.trim();
    let (sign, rest) = match value.strip_prefix('-') {
        Some(rest) => (-1, rest),
        None => (1, value.strip_prefix('+').unwrap_or(value)),
    };
    let rest = rest.strip_prefix('P')?;
    let (mut total, mut number) = (0i64, String::new());
    for c in rest.chars() {
        match c {
            '0'..='9' => number.push(c),
            'T' => {}
            unit => {
                let n: i64 = number.parse().ok()?;
                number.clear();
                let seconds = match unit {
                    'W' => 7 * 86_400,
                    'D' => 86_400,
                    'H' => 3_600,
                    'M' => 60,
                    'S' => 1,
                    _ => return None,
                };
                total = total.checked_add(n.checked_mul(seconds)?)?;
            }
        }
    }
    number.is_empty().then_some(sign * total)
}

fn due_start(due: &Due) -> Option<i64> {
    match due {
        Due::At(ts) => Some(*ts),
        Due::Date(date) => Local
            .from_local_datetime(&date.and_hms_opt(0, 0, 0)?)
            .earliest()
            .map(|t| t.timestamp()),
    }
}

impl Default for Calendar {

impl Calendar {
    pub fn new() -> Calendar {
        Calendar {
            before: vec![
                Line::new("BEGIN", "", "VCALENDAR"),
                Line::new("VERSION", "", "2.0"),
                Line::new("PRODID", "", "-//Postvak//Tasks//EN"),
            ],
            todo: Vec::new(),
            after: vec![Line::new("END", "", "VCALENDAR")],
        }
    }

    /// Indices of the VTODO's own lines, skipping nested components.
    fn top(&self) -> Vec<usize> {
        let mut depth = 0usize;
        let mut top = Vec::new();
        for (i, line) in self.todo.iter().enumerate() {
            match line.name.as_str() {
                "BEGIN" => depth += 1,
                "END" => depth = depth.saturating_sub(1),
                _ if depth == 0 => top.push(i),
                _ => {}
            }
        }
        top
    }

    fn get(&self, name: &str) -> Option<&Line> {
        self.top().into_iter().map(|i| &self.todo[i]).find(|l| l.name == name)
    }

    fn text(&self, name: &str) -> Option<String> {
        self.get(name).map(|l| unescape(&l.value))
    }

    fn remove(&mut self, name: &str) {
        let doomed: Vec<usize> = self.top().into_iter().filter(|&i| self.todo[i].name == name).collect();
        for i in doomed.into_iter().rev() {
            self.todo.remove(i);
        }
    }

    /// Replaces the first `name` line, or appends one.
    fn set(&mut self, name: &str, params: &str, value: impl Into<String>) {
        let line = Line::new(name, params, value);
        match self.top().into_iter().find(|&i| self.todo[i].name == name) {
            Some(i) => self.todo[i] = line,
            None => self.todo.push(line),
        }
    }

    /// The line range of the first VALARM, `BEGIN` to `END` inclusive.
    fn first_alarm(&self) -> Option<std::ops::Range<usize>> {
        let start = self
            .todo
            .iter()
            .position(|l| l.name == "BEGIN" && l.value.eq_ignore_ascii_case("VALARM"))?;
        let end = self.todo[start..]
            .iter()
            .position(|l| l.name == "END" && l.value.eq_ignore_ascii_case("VALARM"))?;
        Some(start..start + end + 1)
    }

    fn reminder(&self, due: Option<&Due>) -> Option<i64> {
        let alarm = self.first_alarm()?;
        let trigger = self.todo[alarm].iter().find(|l| l.name == "TRIGGER")?;
        if trigger.params.to_ascii_uppercase().contains("VALUE=DATE-TIME") {
            return parse_time(&trigger.value);
        }
        Some(due_start(due?)? + parse_duration(&trigger.value)?)
    }

    pub fn fields(&self) -> Result<Fields, IcalError> {
        let uid = self.text("UID").filter(|u| !u.trim().is_empty()).ok_or(IcalError::NoUid)?;
        let due = self.get("DUE").and_then(|l| parse_due(&l.value));
        let tags = self
            .top()
            .into_iter()
            .map(|i| &self.todo[i])
            .filter(|l| l.name == "CATEGORIES")
            .flat_map(|l| split_list(&l.value))
            .collect();
        Ok(Fields {
            uid,
            title: self.text("SUMMARY").unwrap_or_default(),
            notes: self.text("DESCRIPTION").unwrap_or_default(),
            reminder: self.reminder(due.as_ref()),
            due,
            priority: Priority::from_ical(self.get("PRIORITY").and_then(|l| l.value.trim().parse().ok()).unwrap_or(0)),
            tags,
            done: self.get("STATUS").is_some_and(|l| l.value.trim().eq_ignore_ascii_case("COMPLETED")),
            completed_at: self.get("COMPLETED").and_then(|l| parse_time(&l.value)),
            original_list: self.text("X-POSTVAK-LIST"),
            sequence: self.get("SEQUENCE").and_then(|l| l.value.trim().parse().ok()).unwrap_or(0),
            modified: self
                .get("LAST-MODIFIED")
                .or_else(|| self.get("DTSTAMP"))
                .and_then(|l| parse_time(&l.value))
                .unwrap_or(0),
        })
    }

    /// Writes the fields that differ from what the calendar holds now, so untouched lines (and their parameters)
    /// stay as they were. `SEQUENCE`, `LAST-MODIFIED` and `DTSTAMP` are always written.
    pub fn set_fields(&mut self, new: &Fields) {
        let old = self.fields().ok();
        let changed = |pick: &dyn Fn(&Fields) -> bool| old.as_ref().is_none_or(|old| pick(old));
        if changed(&|o| o.uid != new.uid) {
            self.set("UID", "", escape(&new.uid));
        }
        if changed(&|o| o.title != new.title) {
            self.set("SUMMARY", "", escape(&new.title));
        }
        if changed(&|o| o.notes != new.notes) {
            match new.notes.is_empty() {
                true => self.remove("DESCRIPTION"),
                false => self.set("DESCRIPTION", "", escape(&new.notes)),
            }
        }
        if changed(&|o| o.due != new.due) {
            match new.due {
                None => self.remove("DUE"),
                Some(Due::Date(date)) => self.set("DUE", ";VALUE=DATE", date.format("%Y%m%d").to_string()),
                Some(Due::At(ts)) => self.set("DUE", "", format_utc(ts)),
            }
        }
        if changed(&|o| o.priority != new.priority) {
            match new.priority {
                Priority::None => self.remove("PRIORITY"),
                p => self.set("PRIORITY", "", p.to_ical().to_string()),
            }
        }
        if changed(&|o| o.tags != new.tags) {
            self.remove("CATEGORIES");
            if !new.tags.is_empty() {
                let value: Vec<String> = new.tags.iter().map(|t| escape(t)).collect();
                self.set("CATEGORIES", "", value.join(","));
            }
        }
        if changed(&|o| o.done != new.done) {
            self.set("STATUS", "", if new.done { "COMPLETED" } else { "NEEDS-ACTION" });
        }
        if changed(&|o| o.completed_at != new.completed_at) {
            match new.completed_at {
                Some(ts) => self.set("COMPLETED", "", format_utc(ts)),
                None => self.remove("COMPLETED"),
            }
        }
        if changed(&|o| o.original_list != new.original_list) {
            match &new.original_list {
                Some(list) => self.set("X-POSTVAK-LIST", "", escape(list)),
                None => self.remove("X-POSTVAK-LIST"),
            }
        }
        if changed(&|o| o.reminder != new.reminder) {
            let alarm = new.reminder.map(|ts| {
                vec![
                    Line::new("BEGIN", "", "VALARM"),
                    Line::new("ACTION", "", "DISPLAY"),
                    Line::new("DESCRIPTION", "", escape(&new.title)),
                    Line::new("TRIGGER", ";VALUE=DATE-TIME", format_utc(ts)),
                    Line::new("END", "", "VALARM"),
                ]
            });
            match (self.first_alarm(), alarm) {
                (Some(range), Some(lines)) => {
                    self.todo.splice(range, lines);
                }
                (Some(range), None) => {
                    self.todo.drain(range);
                }
                (None, Some(lines)) => self.todo.extend(lines),
                (None, None) => {}
            }
        }
        self.set("SEQUENCE", "", new.sequence.to_string());
        self.set("LAST-MODIFIED", "", format_utc(new.modified));
        self.set("DTSTAMP", "", format_utc(new.modified));
    }

    /// The calendar as text, CRLF line ends, folded at 75 octets on character boundaries.
    pub fn to_text(&self) -> String {
        let mut out = String::new();
        let todo = [Line::new("BEGIN", "", "VTODO")]
            .into_iter()
            .chain(self.todo.iter().cloned())
            .chain([Line::new("END", "", "VTODO")]);
        for line in self.before.iter().cloned().chain(todo).chain(self.after.iter().cloned()) {
            let text = format!("{}{}:{}", line.name, line.params, line.value);
            let mut width = 0;
            for c in text.chars() {
                if width + c.len_utf8() > 75 {
                    out.push_str("\r\n ");
                    width = 1;
                }
                out.push(c);
                width += c.len_utf8();
            }
            out.push_str("\r\n");
        }
        out
    }
}
```

```rust
//! The quick-add line: `call Bob tomorrow 9:00 #work !1 ^Errands`. English date words only.

use chrono::{Datelike, Duration, NaiveDate, Weekday};
use serde::{Deserialize, Serialize};

use super::{Due, Priority, local_timestamp};

#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize)]
pub struct Draft {
    pub title: String,
    pub due: Option<Due>,
    pub priority: Priority,
    pub tags: Vec<String>,
    pub list: Option<String>,
}

const WEEKDAYS: [(&str, Weekday); 7] = [
    ("monday", Weekday::Mon),
    ("tuesday", Weekday::Tue),
    ("wednesday", Weekday::Wed),
    ("thursday", Weekday::Thu),
    ("friday", Weekday::Fri),
    ("saturday", Weekday::Sat),
    ("sunday", Weekday::Sun),
];

/// A date starting at `words[0]` and how many words it took.
fn date_at(words: &[&str], today: NaiveDate) -> Option<(NaiveDate, usize)> {
    let word = words.first()?.to_lowercase();
    match word.as_str() {
        "today" => return Some((today, 1)),
        "tomorrow" => return Some((today.checked_add_signed(Duration::days(1))?, 1)),
        "in" => {
            let n: i64 = words.get(1)?.parse().ok()?;
            let unit = words.get(2)?.to_lowercase();
            if !matches!(unit.as_str(), "day" | "days") || !(0..=3650).contains(&n) {
                return None;
            }
            return Some((today.checked_add_signed(Duration::days(n))?, 3));
        }
        _ => {}
    }
    if let Some((_, weekday)) = WEEKDAYS.iter().find(|(name, _)| *name == word) {
        let ahead = (weekday.num_days_from_monday() + 7 - today.weekday().num_days_from_monday()) % 7;
        let ahead = if ahead == 0 { 7 } else { ahead };
        return Some((today.checked_add_signed(Duration::days(i64::from(ahead)))?, 1));
    }
    NaiveDate::parse_from_str(&word, "%Y-%m-%d").ok().map(|d| (d, 1))
}

fn time_of(word: &str) -> Option<(u32, u32)> {
    let (h, m) = word.split_once(':')?;
    let (h, m): (u32, u32) = (h.parse().ok()?, m.parse().ok()?);
    (h < 24 && m < 60 && word.len() <= 5).then_some((h, m))
}

pub fn parse(text: &str, today: NaiveDate) -> Draft {
    let words: Vec<&str> = text.split_whitespace().collect();
    let mut draft = Draft::default();
    // Title words with their positions, so a date that goes back into the title keeps its place.
    let mut title: Vec<(usize, &str)> = Vec::new();
    let mut date = None;
    let mut time = None;
    let mut i = 0;
    while i < words.len() {
        let word = words[i];
        if let Some(tag) = word.strip_prefix('#').filter(|t| !t.is_empty() && !t.contains('#')) {
            draft.tags.push(tag.to_string());
        } else if let Some(p) = word.strip_prefix('!').and_then(|p| match p {
            "1" => Some(Priority::High),
            "2" => Some(Priority::Medium),
            "3" => Some(Priority::Low),
            _ => None,
        }) {
            draft.priority = p;
        } else if let Some(list) = word.strip_prefix('^').filter(|l| !l.is_empty()) {
            draft.list = Some(list.to_string());
        } else if let Some(hm) = time_of(word) {
            time = Some(hm);
        } else if let Some((found, used)) = date_at(&words[i..], today) {
            // A later date wins; the earlier one goes back into the title.
            if let Some((_, start, len)) = date.replace((found, i, used)) {
                title.extend((start..start + len).map(|j| (j, words[j])));
            }
            i += used;
            continue;
        } else {
            title.push((i, word));
        }
        i += 1;
    }
    title.sort_by_key(|(index, _)| *index);
    draft.title = title.iter().map(|(_, word)| *word).collect::<Vec<_>>().join(" ");
    draft.due = match (date.map(|(d, _, _)| d), time) {
        (Some(d), None) => Some(Due::Date(d)),
        (d, Some((h, m))) => local_timestamp(d.unwrap_or(today), h, m).map(Due::At),
        (None, None) => None,
    };
    draft
}

/// A due date on its own, from the same words as quick add.
pub fn parse_date(text: &str, today: NaiveDate) -> Option<Due> {
    let draft = parse(text, today);
    draft.title.is_empty().then_some(draft.due).flatten()
}
```

```rust
//! The task message: `multipart/alternative` with the notes as `text/plain` and the VTODO as `text/calendar`, in
//! `multipart/mixed` with the original mail as `message/rfc822` when the task was made from one.

use mail_builder::MessageBuilder;
use mail_builder::headers::content_type::ContentType;
use mail_builder::mime::MimePart;
use mail_parser::{MessageParser, MimeHeaders};

use super::ical::{Calendar, Fields};

pub fn build(from: &str, cal: &Calendar, fields: &Fields, attached: Option<&[u8]>) -> Vec<u8> {
    let calendar = cal.to_text();
    let alternative = MimePart::new(
        "multipart/alternative",
        vec![
            MimePart::new("text/plain", fields.notes.as_str()),
            MimePart::new(
                ContentType::new("text/calendar")
                    .attribute("charset", "utf-8")
                    .attribute("component", "VTODO"),
                calendar.as_str(),
            ),
        ],
    );
    let body = match attached {
        None => alternative,
        Some(original) => MimePart::new(
            "multipart/mixed",
            vec![
                alternative,
                MimePart::new("message/rfc822", original)
                    .attachment("original.eml")
                    .transfer_encoding("8bit"),
            ],
        ),
    };
    let message_id = format!("{}.{}.{}", fields.uid, fields.sequence, fields.modified);
    MessageBuilder::new()
        .from(from)
        .subject(fields.title.as_str())
        .message_id(message_id)
        .date(fields.modified)
        .header("X-Postvak-Task", mail_builder::headers::raw::Raw::new("1"))
        .body(body)
        .write_to_vec()
        .unwrap_or_default()
}

fn part_bytes(raw: &[u8], wanted: (&str, &str)) -> Option<Vec<u8>> {
    let message = MessageParser::default().parse(raw)?;
    message.parts.iter().find_map(|part| {
        let ct = part.content_type()?;
        (ct.ctype().eq_ignore_ascii_case(wanted.0) && ct.subtype().is_some_and(|s| s.eq_ignore_ascii_case(wanted.1)))
            .then(|| part.contents().to_vec())
    })
}

pub fn calendar(raw: &[u8]) -> Option<String> {
    part_bytes(raw, ("text", "calendar")).map(|bytes| String::from_utf8_lossy(&bytes).into_owned())
}

pub fn attached(raw: &[u8]) -> Option<Vec<u8>> {
    let message = MessageParser::default().parse(raw)?;
    message.parts.iter().find_map(|part| match &part.body {
        mail_parser::PartType::Message(inner) => Some(inner.raw_message().to_vec()),
        _ => None,
    })
}
```

```rust
/// The local-time edges the smart views compare against.
#[derive(Debug, Clone, PartialEq)]
pub struct Bounds {
    pub today: NaiveDate,
    pub now: i64,
    /// Start of today and of tomorrow.
    pub day_start: i64,
    pub day_end: i64,
    /// The last day of "next 7 days", and the start of the day after it.
    pub week_end: NaiveDate,
    pub week_stop: i64,
}

impl Bounds {
    pub fn at(today: NaiveDate, now: i64) -> Bounds {
        let start = |days: i64| {
            today
                .checked_add_signed(chrono::Duration::days(days))
                .and_then(|d| local_timestamp(d, 0, 0))
                .unwrap_or(i64::MAX)
        };
        Bounds {
            today,
            now,
            day_start: start(0),
            day_end: start(1),
            week_end: today.checked_add_signed(chrono::Duration::days(6)).unwrap_or(today),
            week_stop: start(7),
        }
    }

    pub fn now() -> Bounds {
        let now = chrono::Local::now();
        Bounds::at(now.date_naive(), now.timestamp())
    }
}
```

```rust
                &format!("t.done = 0 AND EXISTS (SELECT 1 FROM json_each(t.tags) WHERE value = ?1) {OPEN_ORDER}"),

            ),
            View::Done => self.task_rows("t.done = 1 ORDER BY t.completed_at DESC, t.title", &[]),

            .execute("INSERT OR IGNORE INTO task_reminders (uid, at) VALUES (?1, ?2)", params![uid, at])?;
```

```rust
//! Lists are the folders under the account's tasks folder: the folder itself is Inbox, `Done` holds completed tasks.

use crate::store::{Store, StoreError};

pub const DONE: &str = "Done";

#[derive(Debug, Clone, PartialEq)]
pub struct Root {
    pub name: String,
    pub delimiter: String,
}

impl Root {
    pub fn of(store: &Store, tasks_folder: &str) -> Result<Root, StoreError> {
        let folders = store.folders()?;
        let delimiter = folders
            .iter()
            .find(|f| f.name == tasks_folder)
            .and_then(|f| f.delimiter.clone())
            .or_else(|| folders.iter().find_map(|f| f.delimiter.clone()))
            .unwrap_or_else(|| "/".into());
        Ok(Root { name: tasks_folder.to_string(), delimiter })
    }

    pub fn folder_of(&self, list: &str) -> String {
        match list {
            "" => self.name.clone(),
            list => format!("{}{}{list}", self.name, self.delimiter),
        }
    }

    pub fn list_of(&self, folder: &str) -> Option<String> {
        if folder == self.name {
            return Some(String::new());
        }
        let rest = folder.strip_prefix(&self.name)?.strip_prefix(self.delimiter.as_str())?;
        (!rest.is_empty()).then(|| rest.to_string())
    }

    pub fn done(&self) -> String {
        self.folder_of(DONE)
    }

    pub fn folders(&self, store: &Store) -> Result<Vec<String>, StoreError> {
        let mut names: Vec<String> = store
            .folders()?
            .into_iter()
            .map(|f| f.name)
            .filter(|name| self.list_of(name).is_some())
            .collect();
        names.sort();
        Ok(names)
    }

    pub fn lists(&self, store: &Store) -> Result<Vec<String>, StoreError> {
        Ok(self
            .folders(store)?
            .iter()
            .filter_map(|f| self.list_of(f))
            .filter(|list| !list.is_empty() && list != DONE)
            .collect())
    }
}

pub fn valid_list_name(name: &str, delimiter: &str) -> Result<(), String> {
    if name.trim().is_empty() {
        return Err("a list needs a name".into());
    }
    if name.eq_ignore_ascii_case(DONE) {
        return Err("'Done' holds completed tasks and cannot be a list".into());
    }
    if name.contains(delimiter) || name.chars().any(char::is_control) {
        return Err(format!("a list name cannot contain '{delimiter}' or control characters"));
    }
    Ok(())
}
```

```rust
//! Turns synced messages under the tasks folder into `tasks` rows, and settles duplicate copies of one task.

use crate::actions::{ActionError, select_synced};
use crate::mail_ops::MailOps;
use crate::message::{clean, synthetic_message_id};
use crate::rules::apply::ensure_raw;
use crate::store::{Message, Store};

use super::lists::{DONE, Root};
use super::{Priority, Task, ical, mail};

pub fn task_of(root: &Root, msg: &Message, raw: &[u8]) -> (Task, u32, i64) {
    let folder_list = root.list_of(&msg.folder).unwrap_or_default();
    let in_done = folder_list == DONE;
    let subject = clean(msg.subject.as_deref().unwrap_or(""), false);
    let fallback_uid = msg
        .message_id
        .clone()
        .unwrap_or_else(|| synthetic_message_id(&msg.folder, msg.uid))
        .trim_matches(['<', '>'])
        .to_string();
    let mut task = Task {
        uid: fallback_uid,
        list: if in_done { String::new() } else { folder_list.clone() },
        title: subject,
        notes: String::new(),
        due: None,
        priority: Priority::None,
        tags: Vec::new(),
        done: in_done,
        completed_at: None,
        reminder: None,
        folder: msg.folder.clone(),
        message_uid: msg.uid,
        read_only: false,
        has_mail: mail::attached(raw).is_some(),
    };
    let Some(text) = mail::calendar(raw) else {
        return (task, 0, msg.internaldate);
    };
    match ical::parse(&text).and_then(|cal| cal.fields()) {
        Ok(f) => {
            task.uid = f.uid;
            if !f.title.is_empty() {
                task.title = f.title;
            }
            task.notes = f.notes;
            task.due = f.due;
            task.priority = f.priority;
            task.tags = f.tags;
            task.done = f.done || in_done;
            task.completed_at = f.completed_at;
            task.reminder = f.reminder;
            if in_done {
                task.list = f.original_list.unwrap_or_default();
            }
            (task, f.sequence, f.modified)
        }
        Err(e) => {
            log::warn!("{}/{}: unreadable task: {e}", msg.folder, msg.uid);
            task.read_only = true;
            (task, 0, msg.internaldate)
        }
    }
}

pub fn index(ops: &mut dyn MailOps, store: &Store, tasks_folder: &str) -> Result<usize, ActionError> {
    let root = Root::of(store, tasks_folder)?;
    let mut indexed = 0;
    for folder in root.folders(store)? {
        let pending = store.unindexed_tasks(&folder)?;
        if pending.is_empty() {
            continue;
        }
        select_synced(ops, store, &folder)?;
        for msg in pending {
            let raw = ensure_raw(&msg, ops, store)?;
            let (task, sequence, modified) = task_of(&root, &msg, &raw);
            store.upsert_task(&task, sequence, modified)?;
            indexed += 1;
        }
    }
    drop_duplicates(ops, store)?;
    Ok(indexed)
}

/// Expunges every copy of a task but the winner (highest SEQUENCE, then latest LAST-MODIFIED).
fn drop_duplicates(ops: &mut dyn MailOps, store: &Store) -> Result<(), ActionError> {
    let mut winner: Option<String> = None;
    for copy in store.duplicate_tasks()? {
        if winner.as_deref() != Some(copy.uid.as_str()) {
            winner = Some(copy.uid.clone());
            continue;
        }
        select_synced(ops, store, &copy.folder)?;
        ops.add_flags(copy.message_uid, &["\\Deleted"])?;
        ops.expunge(copy.message_uid)?;
        store.remove_message(&copy.folder, copy.message_uid)?;
        log::info!("{}: dropped an older copy of task {}", copy.folder, copy.uid);
    }
    Ok(())
}
```

```rust
//! Every change to a task: write the new version, then remove the old one. A failure in between leaves a duplicate
//! that the next index settles, never a lost task.

use serde::{Deserialize, Serialize};

use crate::actions::{self, ActionError, select_synced};
use crate::config::AccountConfig;
use crate::mail_ops::{MailError, MailOps};
use crate::rules::Action;
use crate::rules::apply::{ApplyError, ensure_raw};

use super::quick_add::Draft;
use super::{Due, Priority, Task, mail, new_uid};

#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize)]
pub enum Change<T> {
    #[default]
    Keep,
    Clear,
    Set(T),
}

impl<T: Clone> Change<T> {
    fn apply(&self, value: &mut Option<T>) {
        match self {
            Change::Keep => {}
            Change::Clear => *value = None,
            Change::Set(new) => *value = Some(new.clone()),
        }
    }
}

#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize)]
pub struct Patch {
    pub title: Option<String>,
    pub notes: Option<String>,
    pub due: Change<Due>,
    pub priority: Option<Priority>,
    pub tags: Option<Vec<String>>,
    pub reminder: Change<i64>,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub enum TaskOp {
    Create { draft: Draft, notes: String, done: bool, reminder: Option<i64> },
    Update { uid: String, patch: Patch },
    Complete { uid: String },
    Reopen { uid: String },
    Delete { uid: String },
    Move { uid: String, list: String },
    FromMail { folder: String, uid: u32, draft: Draft },
    CreateList { name: String },
    RenameList { from: String, to: String },
    DeleteList { name: String },
}

/// The task the write ended with, and the folders to sync so the new version is indexed.
#[derive(Debug, Clone, PartialEq)]
pub struct Written {
    pub uid: String,
    pub folders: Vec<String>,
}

#[derive(Debug, thiserror::Error)]
pub enum TaskError {
    #[error(transparent)]
    Action(#[from] ActionError),
    #[error("{0}")]
    Refused(String),
}

impl From<StoreError> for TaskError {
    fn from(e: StoreError) -> TaskError {
        TaskError::Action(e.into())
    }
}

impl From<MailError> for TaskError {
    fn from(e: MailError) -> TaskError {
        TaskError::Action(e.into())
    }
}

impl From<ApplyError> for TaskError {
    fn from(e: ApplyError) -> TaskError {
        TaskError::Action(e.into())
    }
}

fn refused(message: impl Into<String>) -> TaskError {
    TaskError::Refused(message.into())
}

/// Creates `folder` on the server unless the store knows it; a placeholder row lets the next sync adopt it.
fn ensure_folder(ops: &mut dyn MailOps, store: &Store, root: &Root, folder: &str) -> Result<(), TaskError> {
    if store.folder(folder)?.is_some() {
        return Ok(());
    }
    match ops.create_folder(folder) {
        Err(e @ (MailError::Io(_) | MailError::Connect(_))) => return Err(e.into()),
        // It may exist before our first sync of it; a real failure surfaces in the append.
        Err(e) => log::debug!("{folder}: create failed ({e}), appending anyway"),
        Ok(()) => {}
    }
    store.upsert_folder(&Folder {
        name: folder.to_string(),
        uidvalidity: 0,
        last_uid: 0,
        special_use: None,
        delimiter: Some(root.delimiter.clone()),
    })?;
    Ok(())
}

fn append(ops: &mut dyn MailOps, store: &Store, root: &Root, folder: &str, raw: &[u8]) -> Result<(), TaskError> {
    ensure_folder(ops, store, root, folder)?;
    ops.append(folder, raw, &["\\Seen"])?;
    Ok(())
}

/// Removes one message for good: no backup, because a newer version or the attached original holds its content.
fn expunge(ops: &mut dyn MailOps, store: &Store, folder: &str, uid: u32) -> Result<(), TaskError> {
    select_synced(ops, store, folder)?;
    ops.add_flags(uid, &["\\Deleted"])?;
    ops.expunge(uid)?;
    store.remove_message(folder, uid)?;
    Ok(())
}

fn find(store: &Store, uid: &str) -> Result<Task, TaskError> {
    store.task(uid)?.ok_or_else(|| refused(format!("no task {uid}")))
}

fn from_address(account: &AccountConfig) -> String {
    account.address.clone().unwrap_or_else(|| account.username.clone())
}

fn folders(first: String, second: String) -> Vec<String> {
    if first == second { vec![first] } else { vec![first, second] }
}

struct Context<'a> {
    ops: &'a mut dyn MailOps,
    store: &'a Store,
    root: Root,
    from: String,
    now: i64,
}

impl Context<'_> {
    /// Rewrites task `uid` with `edit` applied, into `target` or its own folder.
    fn rewrite(
        &mut self,
        uid: &str,
        target: Option<String>,
        edit: impl FnOnce(&mut Fields, &Task),
    ) -> Result<Written, TaskError> {
        let task = find(self.store, uid)?;
        if task.read_only {
            return Err(refused(format!("task {uid} could not be read; it can only be deleted")));
        }
        select_synced(self.ops, self.store, &task.folder)?;
        let msg = self
            .store
            .message(&task.folder, task.message_uid)?
            .ok_or(ActionError::NotFound { folder: task.folder.clone(), uid: task.message_uid })?;
        let raw = ensure_raw(&msg, self.ops, self.store)?;
        let (mut cal, attached) = match mail::calendar(&raw) {
            Some(text) => (ical::parse(&text).map_err(|e| refused(e.to_string()))?, mail::attached(&raw)),
            // Plain mail: the first edit writes a task message carrying the original.
            None => (Calendar::new(), Some(raw.clone())),
        };
        let mut fields = cal.fields().unwrap_or_else(|_| Fields {
            uid: task.uid.clone(),
            title: task.title.clone(),
            ..Fields::default()
        });
        edit(&mut fields, &task);
        if fields.title.trim().is_empty() {
            return Err(refused("a task needs a title"));
        }
        fields.sequence = fields.sequence.saturating_add(1);
        fields.modified = self.now;
        cal.set_fields(&fields);
        let folder = target.unwrap_or_else(|| task.folder.clone());
        append(self.ops, self.store, &self.root, &folder, &mail::build(&self.from, &cal, &fields, attached.as_deref()))?;
        expunge(self.ops, self.store, &task.folder, task.message_uid)?;
        Ok(Written { uid: fields.uid, folders: folders(folder, task.folder) })
    }

    fn create(&mut self, fields: Fields, list: &str, attached: Option<&[u8]>) -> Result<Written, TaskError> {
        if fields.title.trim().is_empty() {
            return Err(refused("a task needs a title"));
        }
        if !list.is_empty() {
            valid_list_name(list, &self.root.delimiter).map_err(TaskError::Refused)?;
        }
        let folder = if fields.done { self.root.done() } else { self.root.folder_of(list) };
        let mut cal = Calendar::new();
        cal.set_fields(&fields);
        append(self.ops, self.store, &self.root, &folder, &mail::build(&self.from, &cal, &fields, attached))?;
        Ok(Written { uid: fields.uid, folders: vec![folder] })
    }
}

fn draft_fields(draft: Draft, notes: String, done: bool, reminder: Option<i64>, now: i64) -> Fields {
    let list = draft.list.clone().unwrap_or_default();
    Fields {
        uid: new_uid(),
        title: draft.title.trim().to_string(),
        notes,
        due: draft.due,
        priority: draft.priority,
        tags: draft.tags,
        done,
        completed_at: done.then_some(now),
        reminder,
        original_list: done.then_some(list),
        sequence: 0,
        modified: now,
    }
}

pub fn run(
    ops: &mut dyn MailOps,
    store: &Store,
    trash: &Trash,
    account: &AccountConfig,
    op: TaskOp,
    by: &str,
    now: i64,
) -> Result<Written, TaskError> {
    let root = Root::of(store, &account.tasks_folder)?;
    let mut cx = Context { ops, store, root, from: from_address(account), now };
    match op {
        TaskOp::Create { draft, notes, done, reminder } => {
            let list = draft.list.clone().unwrap_or_default();
            cx.create(draft_fields(draft, notes, done, reminder, now), &list, None)
        }
        TaskOp::Update { uid, patch } => cx.rewrite(&uid, None, |f, _| {
            if let Some(title) = &patch.title {
                f.title = title.trim().to_string();
            }
            if let Some(notes) = &patch.notes {
                f.notes = notes.clone();
            }
            patch.due.apply(&mut f.due);
            if let Some(priority) = patch.priority {
                f.priority = priority;
            }
            if let Some(tags) = &patch.tags {
                f.tags = tags.clone();
            }
            patch.reminder.apply(&mut f.reminder);
        }),
        TaskOp::Complete { uid } => {
            let done = cx.root.done();
            cx.rewrite(&uid, Some(done), |f, task| {
                f.done = true;
                f.completed_at = Some(now);
                f.original_list = Some(task.list.clone());
            })
        }
        TaskOp::Reopen { uid } => {
            let task = find(store, &uid)?;
            let lists = cx.root.lists(store)?;
            let list = if task.list.is_empty() || lists.contains(&task.list) { task.list.clone() } else { String::new() };
            let target = cx.root.folder_of(&list);
            cx.rewrite(&uid, Some(target), |f, _| {
                f.done = false;
                f.completed_at = None;
                f.original_list = None;
            })
        }
        TaskOp::Move { uid, list } => {
            if !list.is_empty() {
                valid_list_name(&list, &cx.root.delimiter).map_err(TaskError::Refused)?;
            }
            let task = find(store, &uid)?;
            let target = (!task.done).then(|| cx.root.folder_of(&list));
            cx.rewrite(&uid, target, |f, task| {
                if task.done {
                    f.original_list = Some(list.clone());
                }
            })
        }
        TaskOp::Delete { uid } => {
            let task = find(store, &uid)?;

            expunge(cx.ops, store, &folder, uid)?;
            Ok(Written { folders: folders(written.folders[0].clone(), folder), ..written })
        }
        TaskOp::CreateList { name } => {
            valid_list_name(&name, &cx.root.delimiter).map_err(TaskError::Refused)?;
            let folder = cx.root.folder_of(&name);
            if store.folder(&folder)?.is_some() {
                return Err(refused(format!("list '{name}' already exists")));
            }
            ensure_folder(cx.ops, store, &cx.root, &folder)?;
            Ok(Written { uid: String::new(), folders: vec![folder] })
        }
        TaskOp::RenameList { from, to } => {
            valid_list_name(&to, &cx.root.delimiter).map_err(TaskError::Refused)?;
            if !cx.root.lists(store)?.contains(&from) {
                return Err(refused(format!("no list named '{from}'")));
            }
            let (old, new) = (cx.root.folder_of(&from), cx.root.folder_of(&to));
            cx.ops.rename_folder(&old, &new)?;
            store.remove_folder(&old)?;
            ensure_folder(cx.ops, store, &cx.root, &new)?;
            Ok(Written { uid: String::new(), folders: vec![new] })
        }
        TaskOp::DeleteList { name } => {
            let folder = cx.root.folder_of(&name);
            if !cx.root.lists(store)?.contains(&name) {
                return Err(refused(format!("no list named '{name}'")));
            }
            if store.message_count(&folder)? > 0 {
                return Err(refused(format!("list '{name}' is not empty")));
            }
            cx.ops.delete_folder(&folder)?;
            store.remove_folder(&folder)?;
            Ok(Written { uid: String::new(), folders: Vec::new() })
        }
    }
}
```

```rust
/// The one task whose uid starts with `id`; ambiguity names the candidates.
fn resolve_task(store: &Store, id: &str) -> anyhow::Result<Task> {
    let mut found = store.tasks_with_uid_prefix(id)?;
    match found.len() {
        0 => bail!("no task {id}"),
        1 => Ok(found.remove(0)),
        _ => bail!(
            "{id} matches several tasks: {}",
            found.iter().map(|t| short_id(&t.uid)).collect::<Vec<_>>().join(", ")
        ),
    }
}

/// The part of a uid people type: before `@`, at most 8 characters.
fn short_id(uid: &str) -> &str {
    let local = uid.split('@').next().unwrap_or(uid);
    local.get(..8).unwrap_or(local)
}

fn task_line(task: &Task) -> String {
    let mut line = format!("{}\t{}", short_id(&task.uid), clean(&task.title, false));
    if let Some(due) = &task.due {
        line.push_str(&format!("\t{}", postvak::output::due_text(due)));
    }
    for tag in &task.tags {
        line.push_str(&format!(" #{}", clean(tag, false)));
    }
    if !task.list.is_empty() {
        line.push_str(&format!(" ^{}", clean(&task.list, false)));
    }
    line
}

fn cmd_task(command: TaskCommand, config: &Config, paths: &Paths) -> anyhow::Result<()> {
    let today = chrono::Local::now().date_naive();
    let write = |account: Option<&str>, op: TaskOp| -> anyhow::Result<String> {
        let acc = single_account(config, account)?;
        LazyClient::new(paths).task(&acc.name, op, postvak::actions::RULE_NAME)
    };
    match command {
        TaskCommand::Add { text, account } => {
            let draft = postvak::tasks::quick_add::parse(&text, today);
            let uid = write(account.as_deref(), TaskOp::Create { draft, notes: String::new(), done: false, reminder: None })?;
            println!("added {}", short_id(&uid));
        }
        TaskCommand::List { account, today: t, overdue, next7, done, list, tag, json } => {
            let view = match (t, overdue, next7, done, list, tag) {
                (true, ..) => View::Today,
                (_, true, ..) => View::Overdue,
                (_, _, true, ..) => View::Next7,
                (_, _, _, true, ..) => View::Done,
                (_, _, _, _, Some(list), _) => View::List(list),
                (_, _, _, _, _, Some(tag)) => View::Tag(tag),
                _ => View::Inbox,
            };
            let bounds = Bounds::now();
            for acc in select_accounts(config, account.as_deref())? {
                let store = Store::open_account(paths, &acc.name)?;
                for task in store.tasks(&view, &bounds)? {
                    match json {
                        true => println!("{}", postvak::output::task(&acc.name, &task)),
                        false => println!("{}", task_line(&task)),
                    }
                }
            }
        }
        TaskCommand::Lists { account, json } => {
            for acc in select_accounts(config, account.as_deref())? {
                let store = Store::open_account(paths, &acc.name)?;
                for list in Root::of(&store, &acc.tasks_folder)?.lists(&store)? {
                    match json {
                        true => println!("{}", serde_json::json!({ "account": acc.name, "list": list })),
                        false => println!("{}", clean(&list, false)),
                    }
                }
            }
        }
        TaskCommand::Done { id, account } => task_by_id(config, paths, account.as_deref(), &id, |uid| TaskOp::Complete { uid }, "done")?,
        TaskCommand::Reopen { id, account } => task_by_id(config, paths, account.as_deref(), &id, |uid| TaskOp::Reopen { uid }, "reopened")?,
        TaskCommand::Rm { id, account } => task_by_id(config, paths, account.as_deref(), &id, |uid| TaskOp::Delete { uid }, "deleted")?,
        TaskCommand::Edit { id, account, title, due, priority, tag, list, notes } => {
            let acc = single_account(config, account.as_deref())?;
            let task = resolve_task(&Store::open_account(paths, &acc.name)?, &id)?;
            let due = match due.as_deref() {
                None => Change::Keep,
                Some("none") => Change::Clear,
                Some(text) => Change::Set(
                    postvak::tasks::quick_add::parse_date(text, today).ok_or_else(|| anyhow::anyhow!("not a date: {text}"))?,
                ),
            };
            let priority = priority
                .map(|p| match p.as_str() {
                    "none" => Ok(Priority::None),
                    "low" => Ok(Priority::Low),
                    "medium" => Ok(Priority::Medium),
                    "high" => Ok(Priority::High),
                    other => Err(anyhow::anyhow!("priority is none, low, medium or high, not {other}")),
                })
                .transpose()?;
            let tags = (!tag.is_empty()).then(|| tag.into_iter().filter(|t| !t.is_empty()).collect());
            let patch = Patch { title, notes, due, priority, tags, reminder: Change::Keep };
            let client = LazyClient::new(paths);
            if patch != Patch::default() {

            }
            println!("edited {}", short_id(&task.uid));
        }
    }
    Ok(())
}
```

```rust
pub fn parse_due(text: &str, today: NaiveDate) -> Option<Due> {
    let text = text.trim();
    if let Ok(date) = NaiveDate::parse_from_str(text, "%Y-%m-%d") {

    if let Ok(at) = chrono::DateTime::parse_from_rfc3339(text) {
        return Some(Due::At(at.timestamp()));
    }
    quick_add::parse_date(text, today)
}
```

```rust
//! Task reminders: every 30 s the daemon looks for reminders that came due and shows each once.

use crate::output::due_text;
use crate::paths::Paths;
use crate::store::Store;

const EVERY: i64 = 30;
/// A reminder missed by more than this (the machine slept, the daemon was down) is dropped, not shown late.
const STALE: i64 = 86_400;

pub struct Reminders {
    paths: Paths,
    accounts: Vec<String>,
    checked_at: Option<i64>,
}

impl Reminders {
    pub fn new(paths: Paths, accounts: Vec<String>) -> Reminders {
        Reminders { paths, accounts, checked_at: None }
    }

    pub fn set_accounts(&mut self, accounts: Vec<String>) {
        self.accounts = accounts;
    }

    pub fn due(&self, now: i64) -> bool {
        self.checked_at.is_none_or(|at| now - at >= EVERY)
    }

    pub fn tick(&mut self, now: i64) -> Vec<(String, String)> {
        if !self.due(now) {
            return Vec::new();
        }
        self.checked_at = Some(now);
        let mut shown = Vec::new();
        for account in &self.accounts {
            let store = match Store::open_account(&self.paths, account) {
                Ok(store) => store,
                Err(e) => {
                    log::warn!("{account}: reminders skipped: {e}");
                    continue;
                }
            };
            let due = match store.reminders_due(now - STALE, now) {
                Ok(due) => due,
                Err(e) => {
                    log::warn!("{account}: reminders skipped: {e}");
                    continue;
                }
            };
            for task in due {
                let Some(at) = task.reminder else { continue };
                if let Err(e) = store.mark_reminded(&task.uid, at) {
                    log::warn!("{account}: reminder for {} not recorded: {e}", task.uid);
                    continue;
                }
                let body = task.due.as_ref().map_or_else(String::new, |d| format!("due {}", due_text(d)));
                shown.push((task.title, body));
            }
        }
        shown
    }
}
```

```rust
use std::collections::{HashMap, HashSet};

use postvak::tasks::lists::Root;

use super::app::{Account, App, UiAction};

#[derive(Debug, Default)]
pub(crate) struct TasksState {
    pub cursor: usize,
    pub error: Option<String>,
    pub lists: Vec<String>,
    pub marked: HashSet<String>,
    /// Tasks with a command in flight that hides them from this view (complete, delete, move), by uid.
    pub pending: HashMap<String, usize>,
    pub rows: Vec<Task>,
    pub tags: Vec<String>,
    pub view: Option<TaskView>,
}

impl TasksState {
    pub fn view(&self) -> TaskView {
        self.view.clone().unwrap_or(TaskView::Inbox)
    }

    pub fn reload(&mut self, account: &Account) {
        let Ok(store) = &account.store else { return };
        let view = self.view();
        let loaded = Root::of(store, &account.tasks_folder).and_then(|root| {
            Ok((store.tasks(&view, &Bounds::now())?, root.lists(store)?, store.task_tags()?))
        });
        match loaded {
            Ok((rows, lists, tags)) => {
                let keep = self.current().map(|t| t.uid.clone());
                self.rows = rows;
                self.lists = lists;
                self.tags = tags;
                self.error = None;
                let visible = self.visible();
                let last = visible.len().saturating_sub(1);
                self.cursor = keep
                    .and_then(|uid| visible.iter().position(|t| t.uid == uid))
                    .unwrap_or(self.cursor.min(last));
            }
            Err(e) => self.error = Some(format!("could not read tasks: {e}")),
        }
    }

    pub fn visible(&self) -> Vec<&Task> {
        self.rows.iter().filter(|t| !self.pending.contains_key(&t.uid)).collect()
    }

    pub fn current(&self) -> Option<&Task> {
        self.visible().get(self.cursor).copied()
    }
}

pub(crate) fn due_label(due: &Due, today: NaiveDate) -> (String, bool) {
    let (date, overdue) = match due {
        Due::Date(d) => (*d, *d < today),
        Due::At(ts) => {
            let local = postvak::time::local_time(*ts, "%Y-%m-%d");
            let date = NaiveDate::parse_from_str(&local, "%Y-%m-%d").unwrap_or(today);
            (date, *ts < postvak::time::now())
        }
    };
    let day = match (date - today).num_days() {
        0 => "Today".to_string(),
        1 => "Tomorrow".to_string(),
        -1 => "Yesterday".to_string(),
        _ => date.format("%a %-d %b").to_string(),
    };
    let text = match due {
        Due::At(ts) => format!("{day} {}", postvak::time::clock(*ts)),
        Due::Date(_) => day,
    };
    (text, overdue)
}
```

```rust
#[derive(Clone, Debug, PartialEq)]
pub(crate) struct TaskEdit {
    pub uid: String,
    pub title: String,
    pub notes: String,
    pub due: String,
    pub priority: Priority,
    pub tags: String,
    pub reminder: String,
    /// The list name, `Inbox` for the root.
    pub list: String,
}

impl TaskEdit {
    pub fn of(task: &Task) -> TaskEdit {
        TaskEdit {
            uid: task.uid.clone(),
            title: task.title.clone(),
            notes: task.notes.clone(),
            due: task.due.as_ref().map(postvak::output::due_text).unwrap_or_default(),
            priority: task.priority,
            tags: task.tags.join(", "),
            reminder: task.reminder.map(|ts| postvak::output::due_text(&Due::At(ts))).unwrap_or_default(),
            list: if task.list.is_empty() { "Inbox".into() } else { task.list.clone() },
        }
    }

    pub fn patch(&self, task: &Task, today: NaiveDate) -> Result<(Patch, Option<String>), String> {
        let before = TaskEdit::of(task);
        let mut patch = Patch::default();
        if self.title != before.title {
            patch.title = Some(self.title.clone());
        }
        if self.notes != before.notes {
            patch.notes = Some(self.notes.clone());
        }
        if self.due != before.due {
            patch.due = match self.due.trim() {
                "" => Change::Clear,
                text => Change::Set(postvak::tasks::parse_due(text, today).ok_or(format!("not a date: {text}"))?),
            };
        }
        if self.priority != before.priority {
            patch.priority = Some(self.priority);
        }
        if self.tags != before.tags {
            patch.tags = Some(self.tags.split(',').map(str::trim).filter(|t| !t.is_empty()).map(String::from).collect());
        }
        if self.reminder != before.reminder {
            patch.reminder = match self.reminder.trim() {
                "" => Change::Clear,
                text => match postvak::tasks::parse_due(text, today) {
                    Some(Due::At(ts)) => Change::Set(ts),
                    Some(Due::Date(_)) => return Err("a reminder needs a time, e.g. tomorrow 9:00".into()),
                    None => return Err(format!("not a time: {text}")),
                },
            };
        }
        let list = (self.list != before.list).then(|| if self.list == "Inbox" { String::new() } else { self.list.clone() });
        Ok((patch, list))
    }
}
```

```rust
pub(crate) fn preview(draft: &Draft, today: NaiveDate) -> String {
    if draft.title.is_empty() {
        return "Type a task".into();
    }
    let mut parts = vec![draft.title.clone()];
    if let Some(due) = &draft.due {
        parts.push(due_label(due, today).0);
    }
    let mark = priority_mark(draft.priority);
    if !mark.is_empty() {
        parts.push(mark.into());
    }
    parts.extend(draft.tags.iter().map(|t| format!("#{t}")));
    if let Some(list) = &draft.list {
        parts.push(format!("^{list}"));
    }
    parts.join(" · ")
}
```
